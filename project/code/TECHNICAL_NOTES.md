## 四、遥控器模拟无人机 (LoRa, 2026-08-07 完成)

### 遥控器协议映射
```
协议结构 (lora3a22_uart_transfer):
  joystick[4]  摇杆轴值 (±2047量程): [0]左杆X [1]左杆Y [2]右杆X [3]右杆Y
  key[4]      按键 (按下1松开0): [0]摇杆上 [1]摇杆右 [2]副机左 [3]副机右
  switch_key[4] 拨杆开关 (默认1): [0]左拨杆1 [1]左拨杆2 [2]右拨杆1 [3]右拨杆2

小车信道映射:
  左杆X → 左右平移 (pos_error_y)
  左杆Y → 前后平移 (pos_error_x)
  右杆X → 自转 (angle_target 增量式)
  拨杆1 1→0 → 完赛 (flag=3)
```

### 遥控空闲/断连 → 惯导巡逻 (两级判"丢信标")
遥控器**开机后每50ms必发一帧(即使不操作)**, 不能只靠"收不到帧"判丢信标:
```
A. 断连: 完全收不到帧 (遥控关机) >200ms → flag=2
B. 空闲: 收到帧但摇杆全回中+无按键 >2s    → flag=2 (模拟无人机认为无信标)
两者都累加 flag2_count, ≥10 (FLAG2_DEBOUNCE) 才确认丢信标 → 触发巡逻
```
有操作 (任一摇杆离开死区80 或 按键按下) → flag=1 → 手动控制, 打断巡逻。

### 完赛触发 (拨杆1号)
```
拨杆 switch_key[0] 1→0 (边沿) + mission_armed → race_done=1 → ISR race_locked
两道保险:
  1. 首帧(sw0_prev=0xff)只记录不判定 → 上电/遥控关机读到0不会误触发
  2. 仅 mission_armed 后生效 → 记录航点阶段误碰拨杆不锁车
```

### 巡逻逻辑 (inertial_nav.c)
```
触发: 武装 + 3.5s后 + flag2_count≥10 + 未在巡逻 + 消抖结束
逻辑: 选更近航点导航 → 到达等3s → 无信标切另一航点 → 循环
打断: flag=1 (信标出现) 立即打断, 恢复手动控制
```

## 五、磁力计校准状态 (已完成, 暂关)

### 已完成的硬铁校准
```
HARD_IRON_X = -24325  (2G量程精确值, 2026-08-06 椭圆拟合13760点)
HARD_IRON_Y = -3199   (2G量程精确值)
SOFT_IRON_RATIO = 1.031  (椭圆率<1.1, 无需软铁修正, 未使用)
```
`calculate_heading` 只用了硬铁中心, 软铁系数未在计算中用 (当前可忽略)。
注: 8G值×4估算为X=-27240/Y=-3188, 实际拟合X偏了~2900 (增益非精确4倍 + 外部静磁场不随量程缩放), 2G正式校准必要。

### 校准工具链
```
1. mag_capture.py       # 椭圆校准: KEY4开始/结束, 转圈采集
2. mag_calibration.py   # 椭圆拟合: 输出中心/轴/旋转角
3. mag_motor_test.py    # 电机干扰: 分档5%→30%开环
4. mag_yaw_verify.py    # 航向验证: 转圈对比三路yaw
```

### 校准发现的关键数据
```
转动验证: F(融合)累计354.6° ≈ 实际1圈, 误差仅5° → 校准成功
磁力计最大跳变: 177.5° (转动中) → 动态干扰严重但融合扛住
陀螺G仅累计60.9° (实际360°) → 严重欠积分 (待平地复测确认)
静止时Y波动 ±12° (跨0/360边界)
```

### 磁力计跳变问题 (已解决 2026-08-06)
```
现象: 静止时 Y 偶发大尖峰 (8G时最大270°乱跳, 2G时缩小到稳定+23°)
排查过程:
  ① 中断保护/换模块/OSR_128调整 → 均无效
  ② 量程 8G→2G → 尖峰从乱跳缩小为稳定+23° → 量程放大是主因之一
  ③ 抓原始counts → 尖峰样本的 mx/my 跳到:
       温度寄存器值(2558 = 25.6℃)、控制寄存器值(265/257)、近饱和(±32512)
     → 结论: 不是磁场扰动, 是软I2C错位读(读到错误寄存器)
根因: EMI 导致软I2C字节流错位
解法(已实现):
  1. 量程 8G→2G (分辨率4倍)
  2. qmc5883l_get_mag 加错位读过滤: 单次跳变>3500counts → 丢弃本帧
验证: 静止80s拦下25次错位读, Y全程无尖峰(最大跳1.4°)
```

### 电机带载干扰 (已测 2026-08-06)
```
无载偏移: ±16counts
带载偏移: Δmag≈890counts (0.07G), 但航向偏移仅0.8°
融合yaw漂移: -1.3° (可忽略)
结论: 无需动态补偿
```

## 九、操作流程 (遥控模拟, 当前)

```
1. 上电 → PID自动启动 → 遥控开机(不操作)
2. KEY_3 → 关闭PID (进入记录流程)
3. KEY_4×4 → 记录航点1/航点2 (start/end各两次)
4. KEY_4(第5次) → 武装发车, 等3.5s
5. 遥控空闲2s无操作 → flag=2 → 巡逻自动开始
   推摇杆 → flag=1 → 手动控制 (巡逻被打断)
6. 完赛: 拨1号拨杆 1→0 → 锁定停车
7. KEY_3 → 随时停止
```

## 十一、关键坑位提醒

1. **10kHz PWM**: zf_driver_pwm.c分频9u + PWM_DUTY_MAX=1000 (勿动)
2. **ISR禁printf**: 浮点printf会卡死10ms中断
3. **PID覆盖开环**: 测试开环PWM必须先 Motor_Enable_PID(0)
4. **pos_error是static**: App层写入用 SetPositionError()
5. **编码**: project/为UTF-8, libraries/大部分GBK (改注释注意)
6. **遥控器50ms必发帧**: 不能只靠"收不到帧"判丢信标, 必须加空闲判定
7. **上电误锁完赛**: 完赛触发必须有首帧保险(0xff) + mission_armed 门控, 否则上电即锁
8. **位置环满推限速**: 满推速度 = 摇杆缩放K × 位置环Kp, 要调快改 APP_STICK_K 或 POS_V_MAX
